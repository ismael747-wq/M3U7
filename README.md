# Ejercico del modulo 3 95410
## Trabajando sobre la tabla 'Vendedores'
En este ejercicio se ejecutan comando de DDL y DML sobre la tabla 'Vendedores'
1- SELECT: para consultar las ventas totales por vendedor.
2- INSERT: para insertar datos nuevos de vendedores.
3- UPDATE: para actualizar los datos de un vendedor.
4- DELETE: para eliminar a un vendedor por su ID.
